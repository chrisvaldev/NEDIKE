Creating a good course

✓ Choose a clear title that explains what your course teaches.
✓ Write a useful description that sets clear expectations.
✓ Organise your curriculum into logical learning modules.
✓ Include practical learning objectives and requirements.
✓ Use an appropriate cover image to represent your course.
